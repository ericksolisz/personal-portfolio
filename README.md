# Erick Solis Zamacona | Personal Portfolio

This is my personal portfolio. I'm Erick Solis Zamacona, an AI Engineer and Backend Architect. I build AI agents and the backend systems behind them: typed tool-calling agents, multi-tenant APIs and event-driven services. I focus on the parts most devs skip: correctness, security and, above all, testing.

Each project on the site has a short description, the tech it uses, whether it's open or closed source, and a slideshow of demo clips, screenshots and architecture diagrams.

## Featured projects

- **Lead Chat App** *(working title)*: a multi-tenant AI sales assistant for real-estate agents on Messenger and Instagram. It's live in production, in a private beta, and I monitor it in Langfuse. Closed source.
- **Ironsmith**: an event-driven gym membership platform built with Spring Boot microservices, gRPC, Kafka and AWS CDK.
- **Task Management System**: a stateless Spring Boot REST API with JWT auth and authorization in the service layer.
- **Trusty-Web**: an AI browser extension that rates how credible a web page is. It took third place at a hackathon.

## About the site

It's in English and Spanish and works on desktop and mobile. I built it with Next.js, TypeScript, Tailwind CSS and shadcn/ui, and it runs on Vercel.
