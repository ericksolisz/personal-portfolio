# Erick Solis Zamacona — Personal Portfolio

Personal portfolio of **Erick Solis Zamacona**, AI Engineer and Backend Architect. I build AI agents and the backend systems that keep them honest: typed tool-calling agents, multi-tenant APIs, event-driven services and the tests around them.

The site presents my main projects, each with a short description, the technologies used, whether it is open or closed source, and a slideshow of demo clips, screenshots and architecture diagrams.

## Featured projects

- **Lead Chat App** *(working title)* — Multi-tenant AI sales assistant for real-estate agents on Messenger and Instagram. Deployed to production, in a private beta, with observability in Langfuse. Closed source.
- **Ironsmith** — Event-driven gym membership platform: Spring Boot microservices, gRPC, Kafka and AWS CDK.
- **Task Management System** — Stateless Spring Boot REST API with JWT authentication and service-level authorization.
- **Trusty-Web** — AI browser extension that evaluates the credibility of web pages. Third place at a hackathon.

## About the site

Available in English and Spanish, designed for desktop and mobile. Built with Next.js, TypeScript, Tailwind CSS and shadcn/ui, and deployed on Vercel.
